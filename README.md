# Java Expense Tracker

A simple command-line expense tracker built with Java. This project allows users to record, view, and calculate their expenses through an interactive console menu.

## Features

- Add new expenses with a description, amount, and category.
- View all recorded expenses.
- Calculate the total amount spent.
- Interactive menu with input validation for menu options.
- Simple and easy-to-use command-line interface.

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Git and GitHub

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/educkuni/java-expense-tracker.git
   ```

2. Open the project in IntelliJ IDEA.

3. Locate `Main.java` inside the `src` folder.

4. Run the `Main` class.
